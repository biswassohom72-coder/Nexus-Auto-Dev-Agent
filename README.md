# 🌌 NEXUS_CORE v2.0
### Autonomous Multimodal Engineering System

NEXUS_CORE is a next-generation, AI-driven software development agent designed for rapid prototyping, cross-platform voice/text command processing, and autonomous code generation using Google Gemini and LangChain.

---

## 🚀 Key Features
* **Multimodal Command Input:** Supports both WebRTC browser-based voice recording and manual text override.
* **Autonomous Code Synthesis:** Powered by Google Gemini to generate production-ready Streamlit applications.
* **Sci-Fi Command Center UI:** Implements a custom cybernetic interface styled with Orbitron fonts.

## 🛠️ Tech Stack
* Streamlit, Google Gemini API, LangChain, WebRTC (audio-recorder-streamlit)

## 🔑 How to Run
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the agent: `streamlit run ai_agent.py`
4. Provide your Gemini API key in the sidebar and start building!
